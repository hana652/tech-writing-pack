# 04. コロケーション崩れ大全

**このパックの目玉。** ChatGPTやClaudeが生成した日本語でいちばん不自然になりやすいのが、ここで扱う「コロケーション崩れ」です。

## コロケーションとは

コロケーション ＝ **語と語の自然な結びつき**。日本語には「この名詞には、この動詞が付く」という慣用的な組み合わせがある。

- ○ 「課題を**解決**する」　× 「課題を**改善**する」
- ○ 「目標を**達成**する」　× 「目標を**成功**する」
- ○ 「期待に**応える**」　　× 「期待を**満たす**」

意味は通じる。文法も間違っていない。でもネイティブが読むと「なんか変」と感じる。
この「文法は合っているのに不自然」が、AI文章の正体のかなりの部分を占めています。

---

## なぜAIはコロケーションを崩すのか

LLMの仕組みから説明すると、理由は明確です。

1. **近い意味の語に置き換えてしまう**
   AIは「次に来る確率が高い語」を選ぶ。「解決する」と「改善する」は意味が近いので、文脈によっては誤って「改善する」を選ぶ。人間は「課題には解決」という固定の結びつきを丸ごと記憶しているが、AIは1語ずつ確率で選ぶため、慣用句が壊れやすい。

2. **コロケーションは「非合成的」だから**
   「的を射る」は「的」＋「射る」の意味の足し算では説明できない、丸暗記の慣用句。こういう非合成的な結びつきは、確率的生成と相性が悪い。

3. **離れた語どうしの整合が苦手**
   「〜を…する」で名詞と動詞が離れていると、間に修飾語が入るほど結びつきの記憶が薄れ、不自然な動詞を選びやすい。

4. **翻訳調・カタカナ語の混入**
   英語の発想に引っ張られて「影響を作る（make an impact）」のような直訳的結びつきが出る。

> 結論：AIは「意味の近い別の語」で慣用句を上書きしてしまう。
> だから直し方も明確 ──「その名詞に本来付く動詞は何か」を覚える/調べる、です。

---

## 崩れの8タイプ

コロケーション崩れは、大きく8パターンに分類できる。タイプごとに具体例を並べます。

### タイプ1：動詞と目的語のミスマッチ（最頻出）

「名詞＋を＋動詞」で、動詞の選択を誤るパターン。**これが圧倒的に多い**。

| ❌ AIが書きがち | ○ 自然な結びつき |
|---|---|
| 課題を改善する | 課題を**解決**する（改善するのは「状況・品質」） |
| 問題を解消する（軽い問題に） | 問題を**解決**する／不安を**解消**する |
| 目標を成功する | 目標を**達成**する |
| 目標を実現する（数値目標に） | 目標を**達成**する（「夢・構想」なら実現でOK） |
| 効果を与える | 効果を**発揮**する／影響を**与える** |
| 影響を発揮する | 影響を**与える・及ぼす** |
| ニーズを叶える | ニーズを**満たす** |
| 期待を満たす | 期待に**応える** |
| 需要を満たす（やや硬い） | 需要に**応える**／需要を**満たす**（どちらも可） |
| 経験を貯める | 経験を**積む** |
| 知識を覚える | 知識を**身につける・得る** |
| 役割を行う | 役割を**果たす・担う** |
| 責任を行う | 責任を**負う・果たす** |
| 成長を達成する | 成長を**遂げる** |
| 成果を達成する | 成果を**上げる・出す** |
| 対策を作る | 対策を**講じる・とる** |
| 疑問を思う | 疑問を**抱く・持つ** |
| 興味を感じる（やや不自然） | 興味を**持つ・抱く** |
| 違和感を思う | 違和感を**覚える・抱く** |
| 注目を得る | 注目を**集める・浴びる** |
| 信頼を作る | 信頼を**得る・築く** |
| 議論を行う（冗長） | 議論を**交わす・重ねる** |
| リスクを解決する | リスクを**減らす・回避する・低減する** |
| 失敗を解決する | 失敗を**防ぐ**／失敗から**学ぶ** |

### タイプ2：プログラミング文脈の崩れ（技術記事で特に注意）

技術用語×動詞の組み合わせは、AIが特に崩しやすい。意味は通るが不自然になる。

| ❌ AIが書きがち | ○ 自然な結びつき |
|---|---|
| バグを解決する（やや不自然） | バグを**修正する**／エラーを**解決する** |
| エラーを直す（口語寄り） | エラーを**解消・解決する**（記事なら） |
| パフォーマンスを強化する | パフォーマンスを**向上させる・改善する** |
| 速度を向上する（自動詞化ミス） | 速度を**向上させる**／速度が**向上する** |
| 処理を早める（誤字含みがち） | 処理を**速める**／処理を**高速化する** |
| メモリを削減する | メモリ使用量を**減らす・抑える** |
| コストを節約する（やや不自然） | コストを**削減する・抑える** |
| 負荷を減らす | 負荷を**下げる・軽減する** |
| セキュリティを高くする | セキュリティを**高める・強化する** |
| 可読性を上げる | 可読性を**高める** |
| 保守性を強める | 保守性を**高める** |
| テストを行う（冗長） | テストを**する・書く・実行する** |
| 例外を出す（口語） | 例外を**投げる・スローする**（throw） |
| 依存を解決する | 依存関係を**解決する**（resolve は◯）／依存を**減らす** |
| 機能を達成する | 機能を**実装する** |
| 仕様を満たす | 仕様を**満たす**（◯）／要件を**満たす**（◯） |
| 規約を守る | 規約に**従う**／規約を**守る**（どちらも可） |

> 技術記事の鉄則：**「実装する・修正する・実行する・解決する・向上させる」**は付く名詞が決まっている。
> 迷ったら「英単語の動詞（implement / fix / run / resolve）が何に対応するか」で考えると外しにくい。

### タイプ3：自動詞・他動詞の取り違え（が・を）

「が」を取る自動詞と「を」を取る他動詞を混同するパターン。AIは助詞ごと間違える。

| ❌ | ○ |
|---|---|
| 速度を向上する | 速度**が**向上する／速度**を**向上**させる** |
| エラーを発生する | エラー**が**発生する／エラー**を**発生**させる** |
| 処理を完了する（主語が処理なら） | 処理**が**完了する／処理**を**完了**する**（主語が人なら可） |
| 値を変化する | 値**が**変化する／値**を**変化**させる** |
| 状態を更新する（◯）/ 状態を変わる（×） | 状態**が**変わる／状態**を**変える** |

ポイント：「向上・発生・変化・実現」などの**漢語サ変動詞は、自動詞か他動詞かが曖昧**。
他動詞にしたいなら「〜させる」を付ける（向上させる・発生させる）。

### タイプ4：形容詞・連体修飾と名詞のミスマッチ

「形容詞＋名詞」の結びつきの誤り。程度を表す形容詞の選択ミスが多い。

| ❌ | ○ |
|---|---|
| 濃い理解 | 深い理解 |
| 高い課題 | 大きな課題 |
| 大きい精度 | 高い精度 |
| 強い可能性 | 高い可能性／強い可能性（どちらも文脈次第） |
| 濃い相関 | 強い相関／高い相関 |
| 太い影響 | 大きな影響 |
| 重い負荷（◯だが）/ 高い負荷（◯） | 高負荷・負荷が高い |
| ハードルが大きい | ハードルが高い |
| ニーズが強い（やや） | ニーズが高い／需要が高い |

「高い/低い」「深い/浅い」「強い/弱い」「大きい/小さい」は、それぞれ付く名詞が決まっている。
**理解は深い、精度は高い、相関は強い、課題は大きい**。

### タイプ5：副詞と述語の程度ミスマッチ

「副詞＋動詞」で、程度の副詞が動詞に合っていないパターン。

| ❌ | ○ |
|---|---|
| 大幅に解決する | 大幅に**改善する**／完全に**解決する** |
| 劇的に達成する | 劇的に**改善・向上する**／確実に**達成する** |
| 急激に解決する | 急激に**増える・減る**／一気に**解決する** |
| 徐々に達成する | 徐々に**近づく**／着実に**達成する** |
| 圧倒的に解決する | 大幅に**改善する** |

「大幅に・劇的に・急激に」は**変化を表す動詞**（改善・向上・増加・減少）に付く。
「達成・解決・完了」のような**到達点の動詞**には「完全に・確実に・一気に」が合う。

### タイプ6：慣用句・四字熟語の崩し

慣用句を1語入れ替えて壊すパターン。AIは「それっぽい別の語」で慣用句を上書きする。

| ❌ | ○ |
|---|---|
| 的を得る | 的を**射る**（要点を**得る**ならOK） |
| 采配を振う | 采配を**振るう** |
| 物議を呼ぶ | 物議を**醸す** |
| 火蓋を切って落とす（混線） | 火蓋を**切る**／幕を**切って落とす** |
| 嫌気が差す（◯）/ 嫌気を感じる（×） | 嫌気が**差す** |
| 怒り心頭に達する | 怒り心頭に**発する** |
| 雪辱を晴らす（混線） | 雪辱を**果たす**／屈辱を**晴らす** |
| 汚名を回復する | 汚名を**返上する**／名誉を**回復する** |
| 足元をすくわれる | 足を**すくわれる** |
| 公算が強い | 公算が**大きい** |

技術記事ではあまり四字熟語を使わない方が安全。**使うなら正確に**。自信がなければ平易な言葉に言い換える。

### タイプ7：重言（意味の重複）

同じ意味を重ねてしまうパターン。AIは丁寧に書こうとして重複を作る。

| ❌ 重言 | ○ |
|---|---|
| まず最初に | まず／最初に（どちらか一方） |
| 各〜ごとに | 〜ごとに／各〜 |
| 約〜程度 | 約〜／〜程度 |
| 一番最初 | 最初／一番先 |
| 必ず必要 | 必要／必ず要る |
| 後で後悔する | 後悔する |
| 違和感を感じる | 違和感を覚える／違和感がある |
| 過半数を超える | 過半数に達する／半数を超える |
| throw を投げる | 例外を投げる（throw＝投げる） |
| process 処理 | 処理（process＝処理） |
| 頭痛が痛い（極端な例） | 頭が痛い |

技術系で特に出るのが**「英単語＋その和訳」の重複**：「throwを投げる」「inputを入力する」「downloadをダウンロードする」。片方にする。

### タイプ8：翻訳調・カタカナ語の不自然な結びつき

英語の発想に引っ張られた直訳的コロケーション。AIは英語データの影響でこれを出しやすい。

| ❌ 翻訳調 | ○ 自然な日本語 |
|---|---|
| 影響を作る（make an impact） | 影響を与える |
| 決定を作る（make a decision） | 決定する／判断する |
| 努力を作る（make an effort） | 努力する |
| 違いを作る（make a difference） | 違いを生む／効果がある |
| お金を作る（make money、文脈次第） | 稼ぐ |
| 質問を持っている（have a question） | 質問がある |
| 〜を可能にさせる | 〜を可能にする |
| 高いクオリティを持つ | 質が高い |
| ポジティブな影響を与える（冗長） | 良い影響を与える |

## よく使う名詞の「正しい動詞」早見表

技術記事で頻出する名詞に、本来付く動詞をまとめておく。迷ったらここを見る。

| 名詞 | ○ 付く動詞 |
|---|---|
| 課題 | 解決する／取り組む／抱える |
| 問題 | 解決する／解消する／生じる・発生する |
| エラー・バグ | （エラーを）解決する・解消する／（バグを）修正する・直す／発生する |
| 目標 | 達成する／立てる／掲げる |
| 効果 | 発揮する／得る／（効果が）出る・現れる |
| 影響 | 与える／及ぼす／受ける |
| 精度・品質 | 高める／上げる／（精度が）高い |
| パフォーマンス・速度 | 向上させる／改善する／（速度が）上がる |
| コスト | 削減する／抑える／下げる |
| 負荷 | かける／下げる／軽減する |
| セキュリティ | 強化する／高める |
| 可読性・保守性 | 高める／（可読性が）高い |
| リスク | 減らす／回避する／低減する／負う |
| 機能 | 実装する／追加する／持つ |
| 要件・仕様 | 満たす／定義する |
| 知識・スキル | 身につける／得る／習得する |
| 経験 | 積む／得る |
| 信頼 | 得る／築く／失う |
| 責任・役割 | 負う・果たす／担う・果たす |
| 注目 | 集める／浴びる |
| 期待 | 応える（に）／高まる |
| 議論 | 交わす／重ねる／呼ぶ |
| 対策 | 講じる／とる |
| テスト | 書く／実行する／する |
| 例外 | 投げる（throw）／捕捉する（catch） |

## 直し方の手順

1. **「名詞＋を/が＋動詞」の組を抜き出す**
   特に漢語動詞（〜化する・〜する）の前の名詞をチェック。

2. **動詞だけ別の語に置き換えてみて、より自然な方を選ぶ**
   「課題を改善する」→「課題を解決する」の方が自然、と判断する。

3. **迷ったら早見表 or 検索で確認**
   早見表に無ければ、そのコロケーションでGoogle検索して件数・実際の使われ方を見る。公式ドキュメントや技術書での使われ方が参考になる。

4. **重言は片方を消す**
   「まず最初に」→「まず」。「throwを投げる」→「例外を投げる」。

5. **翻訳調は和語に寄せる**
   「影響を作る」→「影響を与える」。

## AIに直させるプロンプト

コロケーション崩れだけを集中して直させたいときは、これを下書きと一緒に投げる（`06-rewriting-prompts.md` にも収録）。

```
以下の文章で、語と語の結びつき（コロケーション）が不自然な箇所を直してください。
意味と事実は変えないこと。

特に次をチェック：
- 動詞と目的語のミスマッチ（例「課題を改善する」→「課題を解決する」）
- 自動詞・他動詞の取り違え（例「速度を向上する」→「速度を向上させる」）
- 形容詞と名詞のミスマッチ（例「濃い理解」→「深い理解」）
- 重言（例「まず最初に」「throwを投げる」）
- 翻訳調（例「影響を作る」→「影響を与える」）

修正した箇所は変更前→変更後で一覧にし、その後に直した全文を出してください。
```
